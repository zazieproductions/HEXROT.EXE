# README diagrams

Every SVG in this directory is generated by [`generate_diagrams.py`](generate_diagrams.py). The script is deterministic, has no third-party dependencies, and writes the six files used by the top-level README.

```sh
python docs/diagrams/generate_diagrams.py
```

| File | Used for | Structure |
|---|---|---|
| `hero.svg` | README banner | Title, palette chips, six-stage pipeline |
| `architecture.svg` | System architecture | Four planes: browser, API, core, sandbox |
| `workflow.svg` | Evidence pipeline | Eight stages, outputs, replay loop, invariants |
| `trust-boundary.svg` | Security model | Host vs sandbox, allowed/denied lists, shared risks |
| `verification.svg` | Verification | Test donut, per-tier bars, CI jobs, build result |
| `guardrails.svg` | Limits | Input, runtime, output/storage ceilings |

## Palette semantics

| Token | Hex | Meaning |
|---|---|---|
| Cyan | `#5AC8F5` | Presentation / interface |
| Green | `#6EE7A8` | Verified local facts, allowed behavior |
| Purple | `#B99CFF` | Deterministic transformation |
| Amber | `#F2C14E` | Evidence, interpretation, environment-gated |
| Red | `#FF6B6B` | Execution, risk, hard limits |
| Slate | `#8FA3B0` | Neutral structure |
| Background | `#0A0F0C` | Canvas |
| Panel | `#101713` | Card surface |
| Border | `#26352C` | Hairline |

The same semantics are repeated in the README legend so a reader can move between prose, diagrams, and tables without re-learning the colors.

## Design constraints

- **Static SVG.** No scripts, external fonts, images, or CDN references. The diagrams render in GitHub and in offline Markdown viewers.
- **Monospace typography.** The font stack is `IBM Plex Mono`, `DejaVu Sans Mono`, then generic monospace. Long labels are wrapped in code, not by the renderer.
- **Dark canvas.** Cards use light text on a dark background; colors carry meaning rather than decoration.
- **Accurate counts.** Test totals, endpoint counts, strategy counts, decoder counts, and limits must match the source. Update both the generator and README when those change.
- **No fabricated data.** The verification chart reflects the local run recorded in the README. It is not a placeholder.

## Preview locally

Render to PNG with any SVG renderer, for example:

```sh
python -c "import resvg_py; open('/tmp/architecture.png','wb').write(resvg_py.svg_to_bytes(svg_path='docs/diagrams/architecture.svg', width=1400, background='#0A0F0C'))"
```

`resvg_py` is an optional local convenience, not a project dependency.
